      <h3>LootCollector</h3>
      <p>LootCollector is a World of Warcraft addon for <strong>Project Ascension</strong>. It finds and tracks Worldforged items, chest spawns, special vendors, and Mystic Scrolls so you can hunt upgrades on WR, CoA, Freepick, and Wildcard realms.</p>
      <p>Install from <a href="https://github.com/gerob/LootCollector/releases">LootCollector Releases</a>: extract the ZIP and copy the addon folders into <code>Interface\AddOns</code>. Source, issues, and updates are in the <a href="https://github.com/gerob/LootCollector">LootCollector GitHub repository</a>.</p>

      <h3>AdiBags-Ascension</h3>
      <p>AdiBags-Ascension is a bag addon for the Project Ascension 3.3.5 client. It is a maintained fork of AdiBags with Ascension bank, keyring, junk, and merchant support.</p>
      <p>Install from <a href="https://github.com/gerob/AdiBags-Ascension/releases">AdiBags-Ascension Releases</a>: extract the ZIP and copy <code>AdiBags</code> and <code>AdiBags_Ascension</code> into <code>Interface\AddOns</code>. Source is in the <a href="https://github.com/gerob/AdiBags-Ascension">AdiBags-Ascension GitHub repository</a>.</p>
